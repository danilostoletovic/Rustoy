# Rustoy

![Rustoy wordmark and multiboot drive emblem](rustoy/assets/rustoy-banner.png)

Rustoy is a Rust multiboot tool for x86-64 UEFI. It builds and inspects GPT disk images, boots Debian Live from exFAT, and includes an experimental path for staging Windows Setup.

See the [build and installation guide](rustoy/README.md) and [implementation status](rustoy/experiments/STATUS.md).

The [historical Ventoy tree](https://github.com/danilostoletovic/Rustoy/tree/9d91f8ab3ea5eea22ea4b83aa305b16fac8dda7c) contains the source for the former hybrid workflow. License records are in [COPYING](COPYING) and [License](License).
